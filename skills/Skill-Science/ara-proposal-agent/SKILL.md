# ARA Proposal Agent

Use this skill for Amazon Research Awards proposal work, especially the Spring 2026 Amazon 2030 / Agentic AI CFP.

## What to do first

1. Read [`references/cfp.md`](references/cfp.md) for the call scope and submission context.
2. Read [`references/program-rules.md`](references/program-rules.md) before giving eligibility or disclosure advice.
3. Read [`references/proposal-template.md`](references/proposal-template.md) when drafting or formatting the proposal itself.

## Core workflow

1. Confirm the proposal target: full draft, section outline, compliance check, or budget review.
2. Check whether the PI and project are eligible under the program rules.
3. Determine whether Appendix C is required because of prior Amazon funding or credits in the last 3 years.
4. Draft the proposal in the official template order:
   - Project title
   - PI and Co-PI details
   - Cash funding needed
   - AWS Promotional Credits needed
   - Amazon contact, if any
   - Abstract
   - Keywords
   - Introduction
   - Methods
   - Expected results
   - Funds needed
   - Additional information
   - Appendices A-C as applicable
5. Make the budget section concrete and compliant.
6. Finish with a submission checklist.

## Working rules

- Use the official template structure instead of inventing a new proposal format.
- Keep the proposal concise and aligned to the stated page limit.
- For cash funding, do not include indirect expenses that are not incurred solely for the project.
- For AWS Promotional Credits, name the AWS products the project will use.
- If prior Amazon support exists, include Appendix C rather than hiding it.
- Flag any ambiguity about eligibility, funding history, or sponsor obligations instead of guessing.

## Output expectations

When the user asks for help, produce one of these:

- A full proposal draft in the official template order
- A section-by-section outline with placeholders
- A funding and eligibility checklist
- A compliance review against the program rules

If the user wants a draft, keep the language proposal-ready and preserve the template headings from the reference file.
