# ARA Program Rules

Official source:

- https://www.amazon.science/research-awards/program-rules

## Eligibility and disclosure points

- The Principal Investigator must be a full-time faculty member at an accredited academic institution or a permanent researcher at a qualifying NGO.
- Each Principal Investigator may submit only one proposal per call for proposals period.
- Amazon employees are not eligible.
- Do not ignore prior Amazon funding, direct or indirect, within the last 3 years.
- If the project team has had prior Amazon cash funding or AWS Promotional Credits, Appendix C is required.

## Budget and submission cautions

- For cash funding, exclude indirect expenses that are not incurred solely for the project.
- For AWS Promotional Credits, name the AWS products you plan to use.
- If eligibility is uncertain, stop and verify before drafting the submission text.
