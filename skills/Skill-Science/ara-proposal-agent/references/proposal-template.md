# Amazon Research Awards Proposal Template

Source:

- https://www.amazon.science/_attachment/ara-proposal-template-agentic-ai-spring-2026?id=0000019d-92f3-d617-afdd-baf744650000

## Proposal Requirements

- Length: maximum of 4 pages, not including appendices.
- Formatting: 11-point font, commonly used legible font, 1-inch margins.
- Final document: one PDF for upload.
- If funded directly or indirectly by Amazon in the last three years, include Appendix C.

## Template Structure

1. Project Title
2. PI
3. Co-PI
4. Cash funding needed
5. AWS Promotional Credits needed
6. Amazon contact, optional
7. Abstract
8. Keywords
9. Introduction
10. Methods
11. Expected results
12. Funds needed
13. Additional information
14. Appendix A - Reference
15. Appendix B - CV of PI
16. Appendix C - Previously Funded Project Summary

## Appendix C prompts

- Project title
- Funding amount and time
- Funding source
- Who was this funding for?
- If AWS Promotional Credits were provided, how much is left?
- Brief summary of results, papers, and open-source software enabled
