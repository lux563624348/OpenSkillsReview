# OpenFinTech

A small, focused collection of Codex skills for finance, econometrics, and data work.

## Skills

- `skills/fred-api` (macro time series from FRED)
- `skills/portfolio-analytics` (performance and risk metrics)
- `skills/sec-edgar` (SEC filings and XBRL data)
- `skills/yfinance` (market data and corporate actions)
- `skills/pdf` (PDF parsing)
- `skills/pptx` (PowerPoint generation)
- `skills/statistical-analysis` (statistical testing and reporting)
- `skills/statsmodels` (econometric modeling)
- `skills/unusual-whales-api` (unusual options flow and market data)
